# Bluewolfchain: เว็บหลักของเชน BWSC

เว็บหลักของเชน Bluewolfchain (BWSC, Program VM, chain id 41234)
- **หน้าแรก (landing page):** นำเสนอเชน: เขียนคอนแทรคด้วย JavaScript (ตัวอย่างโค้ด), block ทุก 2 วินาที, สถานะสด, ความสามารถของเชน, สรุปแอปบนเชนตามหมวด, ขั้นตอนสร้างแอป, ค่า network + ปุ่มเพิ่มเชนลงกระเป๋า
- **Docs (`#/docs`):** คู่มือแบบ Vercel docs (ธีมดำ): ใช้งานเชน, เขียนโปรแกรม, สร้างแอปที่ใช้เชน, HTTP API
- **ดีไซน์:** ไม่ใช้ emoji หรือสัญลักษณ์ตัวอักษร (ใช้ไอคอนเส้น SVG ของเว็บเอง `src/project/ui/icons.js`), พื้นหลังขยับช้า ๆ, เส้นแสงวิ่งตามขอบ, บล็อกโค้ดมีสีไวยากรณ์ + เลขบรรทัด + ปุ่ม Copy (`src/project/ui/code.js`), ฟอนต์ Inter + JetBrains Mono · ผู้ใช้ที่ตั้งค่า "ลดการเคลื่อนไหว" จะไม่เห็นภาพเคลื่อนไหว
- **แอปบนเชน:** **Swap, Bridge, Stake**
- ทุกอย่างทำงานกับโปรแกรมบนเชนตรง ๆ ไม่มีข้อมูลสมมติ
- ข้อความในหน้าเว็บเป็นภาษาอังกฤษทั้งหมด

## เชื่อมกระเป๋า (Reown)

ปุ่ม Connect wallet เปิดหน้าต่างของ **Reown AppKit** (WalletConnect) อย่างเดียว เว็บขอให้กระเป๋า**เซ็น**เท่านั้น ไม่เคยเห็น key
- บน BWSC: เซ็นข้อความ EIP-712 (`eth_signTypedData_v4`) ทุกธุรกรรมของโปรแกรม
- ขั้นของ bridge ที่อยู่บน BSC: กระเป๋าเซ็นธุรกรรมของ BSC เอง
- กระเป๋าที่ใช้ได้: กระเป๋าใน browser (MetaMask, Rabby, OKX …) และกระเป๋ามือถือผ่าน QR / WalletConnect
- ปิด login ด้วย email / social, swap และ on-ramp ในหน้าต่างไว้
- **ไม่ต้องเพิ่มหรือสลับไปเชน BWSC:** node ใช้รูปแบบลายเซ็นเวอร์ชัน 2 (domain `Bluewolfchain` v2 ไม่มี chainId) กระเป๋าเลยเซ็นได้จากเชนไหนก็ได้ที่เปิดอยู่ เว็บใส่เชนนั้นเป็น `signedOnChainId` ให้เอง
  - ถ้า node เปลี่ยนรูปแบบลายเซ็นอีก ต้องแก้ `vendor/bwscbox/src/typedData.js` ให้ตรงกับ `src/crypto/signature.js` ของ node ทุกตัวอักษร

**ตั้งค่า (ครั้งเดียว)**
1. สมัครที่ https://dashboard.reown.com → สร้าง project (AppKit) → ก้อป **Project ID**
2. ใส่ใน `settings/config.js` → `wallet.reownProjectId` (ไม่ใช่ความลับ)
3. ใน dashboard ของ Reown เพิ่มโดเมนเว็บ (`app.siteUrl`) ใน allowed domains
   - ระหว่างพัฒนาให้เพิ่ม `localhost` ด้วย
   - ถ้าไม่เพิ่ม กระเป๋าจะเชื่อมไม่ได้

ถ้ายังไม่ใส่ Project ID เว็บจะขึ้น "Setup is not finished" และบอกว่าขาดอะไร

## โครงโปรเจกต์

```
bwsc-swap/
├── settings/
│   └── config.js          ⚙️  ไฟล์ตั้งค่าไฟล์เดียว: แอป, เชน, แอดเดรสโปรแกรม, เหรียญ, slippage, URL ของ signer
├── src/                   แอป (Vite + vanilla JS + Tailwind v4 + bwscbox + Reown AppKit)
├── public/  index.html  vendor/bwscbox
├── bridge-signer/         บริการเซ็นยอด + ส่งเหรียญอัตโนมัติ (relayer) ของ bridge (รันบนเซิร์ฟเวอร์ของคุณ ไม่ใช่ส่วนของเว็บ) อ่าน settings/config.js เหมือนกัน
└── deploy-kit/            🗑️ ลบได้: โปรแกรมให้ก้อปไปดีพลอยเอง + โค้ดชั่วคราว (เทส, เชนจำลอง)
```

**ใช้งาน 3 ขั้น**
1. **ดีพลอยเอง:** ทำตาม `deploy-kit/README.md` (BWSC ผ่าน explorer, BSC ผ่าน Remix) ทุกไฟล์พร้อมก้อปวาง ไม่มีอะไรดีพลอยอัตโนมัติ
2. **ใส่แอดเดรส + Reown Project ID:** ใน `settings/config.js` (ดู `settings/README.md`)
3. **รันเว็บ:**
   ```bash
   npm install
   npm run dev        # http://localhost:5173
   npm run build      # → dist/
   ```

ดีพลอยเสร็จแล้วลบ `deploy-kit/` ได้ทั้งโฟลเดอร์ เว็บไม่ได้ import อะไรจากในนั้น และ `npm run build` ยังผ่าน

## รองรับของจำนวนมาก

- **คู่เทรด:** ทุกคู่อยู่ในโปรแกรม BwscDex ตัวเดียว คู่ใหม่ไม่ต้องดีพลอยและไม่ต้องแก้เว็บ
  - เพิ่มได้จากหน้า Pool → New pair (หรือ `createPair` ใน explorer)
  - วางแอดเดรส token ใหม่ในช่องค้นหาได้เลย เว็บอ่านชื่อและทศนิยมจากเชน
  - เว็บอ่านคู่ทีละ 100 คู่ต่อ 1 RPC call
- **pool stake:** สร้างได้ไม่จำกัดจากหน้า Stake → New pool (หรือ `createPool`) เว็บอ่านทีละหน้าแบบเดียวกัน
- **bridge:**
  - เส้นทาง = (เชน, เหรียญ) ตั้งได้ทุกแบบ: token↔token, token↔native, native↔token
  - เพิ่มเชนใหม่ได้ไม่จำกัด (เชน EVM ใดก็ได้): ดีพลอย BwscBridgeEvm บนเชนนั้น, `setRoute` ทั้งสองฝั่ง, เพิ่มใน `chains` ของ `settings/config.js` (ขั้นตอนเต็มใน `deploy-kit/README.md`)
  - หน้า Bridge, กระเป๋า และ bridge-signer อ่านจาก `chains` เอง ไม่ต้องแก้โค้ด
  - เชนจำลองในเครื่องมี 2 เชน (BSC + "Ethereum (local)") จึงเทสหลายเชนทุกครั้ง
- **เหรียญใน `tokens`:** ใช้แค่กำหนดลำดับและชื่อเต็ม เหรียญที่ไม่อยู่ในรายการก็ใช้ได้ เว็บอ่านข้อมูลจากเชนเอง
- **ราคา:** ไม่มีราคาที่พิมพ์เองในค่าตั้งแล้ว ทุกราคา (เช่น APR ในหน้า Stake) อ่านจาก pool ของ BwscDex ตอนนั้น คิดเป็น USDT (`prices.unit`) ตาม mid-price ของเส้นทางที่ดีที่สุด เหรียญที่ไม่มีเส้นทางไป USDT จะขึ้น "—" ไม่เดา

## ระบบหลัก

**Swap (BwscDex v2)** · pool แบบ x·y=k (เหมือน Uniswap v2) ทำมาเพื่อดีพลอยครั้งเดียวแล้วใช้ได้นาน
- ทุกคู่อยู่ในโปรแกรมเดียว
- ทุกการเคลื่อนเงินมี **deadline** (เลยเวลา = ไม่รับ), ขั้นต่ำ/ขั้นสูง (slippage) และผู้รับ (`to`)
- สวาปได้ 2 แบบ: จ่ายเท่านี้ (`swap`) หรือได้เท่านี้ (`swapExactOut`)
- ส่วนแบ่ง LP โอนได้ / approve ให้โปรแกรมอื่นได้ (`transferShares`, `approveShares`, `transferSharesFrom`)
- ทุกคู่เก็บราคาเฉลี่ยตามเวลา (TWAP) ไว้ให้โปรแกรมอื่นใช้
- owner ดึง token ที่คนโอนเข้ามาผิดออกได้ (`skim`) เฉพาะส่วนที่เกิน reserve ของทุกคู่
- คู่ token↔token และ token↔BWSC: pool เก็บ BWSC เป็น wBWSC แต่ผู้ใช้ส่งและรับ BWSC ได้ตรง ๆ
- ค่าธรรมเนียมรายคู่ (default 0.30%, สูงสุด 1%) เข้า pool ให้คนวางสภาพคล่อง
- approve ครั้งเดียวต่อเหรียญ ใช้ได้ทุกคู่
- หยุดชั่วคราวแล้วยังถอนสภาพคล่องได้เสมอ
- owner ไม่มีทางแตะเงินใน pool

**Bridge (BWSC เป็นศูนย์กลาง ↔ เชน EVM)** · ล็อกและปล่อยทั้งสองฝั่ง ใช้ยอดสะสม
- ฝากที่ต้นทาง → bridge-signer เซ็นยอดสะสม (EIP-712) → relayer ส่ง claim ให้เอง → ปลายทางจ่าย "ยอดที่เซ็น − ที่เคลมแล้ว"
- ผู้ใช้ไม่ต้องกดเคลม และไม่ต้องมีค่า gas ฝั่งปลายทาง (กระเป๋าใหม่ได้ gas drop) ถ้า relayer ล่ม ผู้ใช้กด "Claim now" เองได้
- ใครส่ง claim ก็ได้ แต่เงินเข้ากระเป๋าเจ้าของเสมอ ลายเซ็นเก่าใช้จ่ายซ้ำไม่ได้
- ค่าธรรมเนียมเป็น % ต่อเส้นทาง หักตอนฝาก

**Staking (BwscStaking)** · 2 เฟส
1. owner สร้าง pool: เลือกเหรียญที่ฝากและเหรียญรางวัล (BWSC native หรือ token ก็ได้ทั้งคู่)
2. owner เติมรางวัลได้ทุกเมื่อ จำนวนและระยะเวลาเท่าไหร่ก็ได้

- **owner ถอนรางวัลออกไม่ได้**
- แบ่งรางวัลทุกวินาทีตามสัดส่วนที่ฝาก
- ถอนเงินฝากและเคลมรางวัลได้เสมอ

**Limit orders (BwscLimit)** · เหรียญแลกเหรียญในราคาที่ผู้ตั้งกำหนด
- ผู้ตั้งฝากเหรียญไว้ในโปรแกรม (เช่น 100 BWSC ขอ 230 USDT) เลือกได้ว่าขายแบ่งได้ไหม และหมดอายุเมื่อไหร่ (1 / 7 / 30 วัน / ไม่หมด)
- ผู้ซื้อจ่ายตามเรทเข้ากระเป๋าผู้ตั้งโดยตรง และได้เหรียญทันทีในธุรกรรมเดียว (หักค่าธรรมเนียมของเหรียญนั้น)
- **owner เพิ่มเหรียญที่อนุญาตเอง** และตั้งค่าธรรมเนียมแยกรายเหรียญ (สูงสุด 5%) ปิดเหรียญชั่วคราวได้
- ผู้ตั้งยกเลิกเอาเหรียญคืนได้เสมอ (แม้ pause / หมดอายุ / เหรียญถูกปิด) owner แตะเหรียญในออเดอร์ไม่ได้ ถอนได้แค่ค่าธรรมเนียม
- รองรับเหรียญและออเดอร์จำนวนมาก: ทุกรายการอ่านทีละหน้า, เรทดีสุดของแต่ละตลาดเก็บไว้บนเชน, เปิดได้ตลาดละ 500 ออเดอร์

ฟังก์ชันทั้งหมดของแต่ละโปรแกรมอธิบายไว้ที่หัวไฟล์ใน `deploy-kit/bwsc/` และ `deploy-kit/bsc/`
